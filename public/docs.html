Reseller API v1 — same pattern as Bay2Game: one key, one wallet, JSON over HTTPS. Use these samples in your website or Telegram bot. Replace YOUR_KEY with the key from Login / Dashboard.

Base URL

All paths are relative to your host.

https://YOUR-HOST/api/v1

JSON only · Amounts in USD · Timestamps ISO-8601 UTC

Authentication

Send your API key on every request:

Authorization: Bearer vt_xxxxxxxx # or X-API-Key: vt_xxxxxxxx

Keys are created automatically when you register. Disabled accounts get 401.

Check balance

GET /me

List games & packages

GET /games

Wholesale prices for your account. Use fields for player inputs.

Single game: GET /games/:id

Create order

POST /orders

Charges the wallet immediately. Poll status for delivery.

FieldRequiredNotes
package_idyesFrom /games
player_idyesUID / username

Same reference → returns original order (no double charge).

Order status

GET /orders/:id

Statuses: processing · success · failed · refunded

List: GET /orders?limit=20
